Full-stack · Issue reporting 01 / 03

CampusFix AI

A campus issue-reporting platform with a React and Vite report form and admin dashboard. Its FastAPI backend validates requests with Pydantic, stores reports in SQLite, and returns a category, priority, and short summary. An offline, object-oriented pipeline that extracts text from PDFs and .txt files, routes each file to the right extractor, and generates structured insights with a locally hosted Llama 3 model. Documents stay on the user's machine; no cloud API is required.
